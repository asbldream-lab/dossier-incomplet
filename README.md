# Dossier Incomplet

Jeu satirique (Godot 4.5) sur le parcours pour obtenir ses papiers en préfecture.
Chaque niveau est une étape administrative : phase action contre des fournitures de bureau hostiles,
puis un boss en combat au tour par tour (parade en temps réel, attaques aux noms très administratifs).

## Lancer
Ouvrir `project.godot` avec Godot 4.5+, puis F5.

**Contrôles** — ZQSD/flèches : bouger · J/clic : frapper · Espace : roulade / parer (pendant le « ! »)

## Contenu
Stats, attaques et textes : `data/combat.json`. Architecture : voir `CLAUDE.md`.
